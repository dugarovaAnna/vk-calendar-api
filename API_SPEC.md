# Спецификация API (без сборщика)

## Эндпоинты

- `GET /categories`
- `GET /events?category=&date_from=&date_to=&q=&page=`
- `GET /events/{id}`

## Параметры запроса (для /events)

| Параметр | Тип | Описание |
|----------|-----|----------|
| `category` | string | Фильтр по категории (например, `концерт`) |
| `date_from` | date (YYYY-MM-DD) | Минимальная дата мероприятия |
| `date_to` | date (YYYY-MM-DD) | Максимальная дата мероприятия |
| `q` | string | Поиск по описанию (подстрока) |
| `page` | integer | Страница (по умолчанию 1, размер страницы 20) |

## Статусы записей

| Статус | Описание |
|--------|----------|
| `verified` | Дата найдена строго в формате ДД.ММ.ГГГГ, можно показывать автоматически |
| `needs_review` | Дата не найдена, требуется ручная проверка модератором |
